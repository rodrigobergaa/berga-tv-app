# Berga TV

Versões do app **Berga TV** para Android, Android TV e PC.

**Baixar a última versão:** [Releases → Latest](../../releases/latest)

- `BergaTV.apk`: celular, TV Box e Android TV
- `BergaTV.ipk`: TV LG (webOS), instalado pelo webOS Dev Manager
- `berga_tv.py`: computador (rode `python berga_tv.py`)

O app verifica atualizações sozinho e instala por cima, mantendo listas e favoritos.
